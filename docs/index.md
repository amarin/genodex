# Genealogy MCP — документация

Сервис для хранения и доступа к данным генеалогического дерева. Предоставляет два внешних интерфейса:

- **MCP** (под `/mcp`) — для AI-ассистентов и других MCP-клиентов;
- **HTTP API + веб-интерфейс** (под `/api`, `/static`, `/`) — для людей.

Бэкенд — Go, собирается в один бинарник. Фронтенд (Vite + React + antd) собирается в `web/dist` и встраивается в бинарник через `go:embed`.
