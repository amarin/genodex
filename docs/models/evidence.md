# Доказательства

Цепочка доказательства — трёхуровневая: утверждение → `Citation` → `Source`.

## Source

`id`, `kind` (`archival-scan`/`transcription`/`document`/`audio`/`photo`/`memory`/`external`),
`title`, `author?`, `date?`, `reliability`, `repository_id?` (строгая ссылка),
`notes []TextRef`, `private`.

- Единая абстракция источника-первоисточника (библиографическая запись):
  1. ссылка на скан страницы дела в архиве (+ область на скане через `anchor.rect`);
  2. документ/аудио/фото/внешний материал;
  3. текстовая расшифровка записи.
- `reliability` — общая достоверность источника (например: первичный документ /
  современная запись / воспоминания / косвенные сведения / неизвестно).
- `repository_id` — физическое место хранения источника (см. [Repository](archives.md));
  пусто, если место неизвестно.
- Конкретный фрагмент источника (страница/скан, расшифровка записи) цитируется через
  `Citation` — см. ниже.
- `private` — приватизационный флаг.

## Citation

`id`, `source_id` (строгая), `anchor Anchor?`, `text?`, `note?`, `private`.

- Переиспользуемая цитата: конкретный фрагмент источника, на который ссылаются
  утверждения. Цепочка доказательства: `SourceLink` → `Citation` → `Source`.
- `source_id` — строгая ссылка на источник (библиографическую запись).
- `anchor` — привязка «где именно» (скан страницы единицы учёта + область, файл с
  тайм-меткой, внешняя ссылка) — см. [Типы значений](values.md).
- `text` — расшифровка/текст записи (переехало с `Source`).
- `note` — примечание к цитате (опционально).
- Одна цитата обслуживает много утверждений: одна запись в деле, из которой взяты
  сведения о нескольких персонах, — одна `Citation`, а не повторение данных в каждом
  утверждении. Повторное цитирование — поиск существующей цитаты по источнику и фрагменту.

## SourceLink

см. [Типы значений](values.md). Применяется к любому утверждению: атрибуты `Person`, `Event`,
`Relation`, `Residence`, `Family`, `Note`, `AdministrativeDivision` и др.
`reliability` здесь — частная: точность именно этого утверждения по этому источнику.

## Attachment

`id`, `kind` (`scan`/`document`/`audio`/`photo`), `uri`/`filename`, `mime`, `page?`,
`node_id` (строгая), `document_id?`, `note`, `private`.

- Файловый объект; сканы страниц единиц учёта привязываются к `ArchiveNode` через
  `node_id` (уточнение до документа внутри единицы — `document_id`), цитата
  ссылается на вложение через `anchor.attachment_id`.
