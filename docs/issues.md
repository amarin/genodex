## Проверка слова-типа в названии единицы деления — грубая эвристика

**Где:** веб, форма создания и редактирования единицы административного
деления, поле «Название» (`typeWordInName` в `web/src/divisionTypes.ts`).

**Что не так:** название проверяется только на целое слово, совпадающее с
названием типа («уезд», «село»), без учёта регистра и разницы ё/е.

- Ложные срабатывания: термин бывает именем собственным (в данных есть село
  «Погост»). Сначала это была ошибка, которая блокировала создание; с
  2026-09-24 (`e61912a`) — только предупреждение, «Создать» не блокирует.
- Пропуски: формы слова («Боровского уезда»), сокращения («д. Иваново»,
  «г. Калуга», «вол.»), тип в составе дефисного слова ловится только по
  части («Иваново-Деревня» → «деревня»).

**Как можно исправить:**
- учитывать падежные формы (например, через морфологию, как в программе
  поиска — `docs/search/`) и типовые сокращения;
- подсвечивать совпадение, только если слово стоит в начале или в конце
  названия (типичное «Боровский уезд» / «уезд Боровский»);
- проверять и при записи через MCP — тоже как предупреждение в результате
  тула, не как ошибку.
