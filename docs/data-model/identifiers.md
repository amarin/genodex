# Идентификаторы

- Строковые, глобально уникальные в хранилище.
- Правило по умолчанию — транслит + дисамбигуатор:
  - персона: `<фамилия>-<имя>-<отчество>`, при совпадении — добавление года
    (`dorozhkin-ivan-1881`) или `-2`;
  - архивная цепочка: `gako-f33-o6-d264` (шифр из метаданных: фонд-опись-дело;
    карточка — `rgva-f01-sh3-ps5-c012`);
  - места и словари: транслит канонической формы (`kaluzhskaya-guberniya`, `davydovo`);
  - род: транслит фамилии.
- Совместимо с vault как одним из вариантов хранилища (там же эти id используются в файлах).
