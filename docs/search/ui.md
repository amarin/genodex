# Интерфейс поиска

> Часть раздела [Поиск по базе](index.md). Подпроект P4.

## Выпадающий список в шапке

- Работает **всегда в пресете «Строго»** — максимально зажатый шум, без учёта
  пользовательских настроек.
- Запрос уходит после паузы ввода (~200 мс); последнее слово ищется как префикс
  ([normalization.md](normalization.md#разбор-запроса)).
- Порядок: сначала словарные результаты («Фамилия: Кузнецов» с действиями), затем
  группы по порядку типов; в группе до 3 результатов, всего до ~5 групп.
- У результата — подпись, путь по иерархии, однострочный фрагмент с подсветкой для
  текстовых доводов.
- «Похожие» — только при нуле точных совпадений, до 3, с явной пометкой.
- Enter или «Все результаты» — страница результатов с тем же запросом.

## Страница результатов

- Строка запроса, **чипы фильтров** ([filters.md](filters.md#интерфейс)),
  переключатель пресета, переключатель группировки, раскрываемый блок «Тонкая
  настройка».
- Результаты с доводами, фрагментами, путём по иерархии, подсказками «также в…»,
  действиями («Искать здесь», действия словарных результатов).
- Счётчики по типам с переходом «только персоны» и т.п.
- Секция **«Похожие»**, когда точных результатов меньше порога.
- **Пустая выдача:** «Ничего не нашлось», предложения (снять фильтр, расширить
  пресет, посмотреть «похожие»). Здесь же — **крючок** для будущей подписки на
  результаты у других узлов (точки интереса,
  [discovery](../exchange/discovery.md)); в этом разделе не проектируется.

## Пресеты

Большинство пользователей переключают только пресет; изменённая вручную опция
переводит пресет в «Свой».

| Опция | Строго | Обычно | Широко |
|---|---|---|---|
| подъём цитаты к целям `SourceLink` | выкл | вкл | вкл |
| двухшаговый путь цитата → событие → участники | выкл | выкл | вкл |
| неоднозначные разборы | только в идентифицирующих полях | вкл | вкл |
| предсказанные леммы | только в идентифицирующих полях | вкл | вкл |
| «похожие» | только при нуле точных | ниже порога | всегда |
| порог «похожих» | — | 5 | — |
| правопреемники делений | выкл | вкл | вкл |
| родственники для фильтра-персоны | выкл | выкл | вкл |

Вне пресетов (настройки отображения): группировка (по умолчанию включена), порядок
типов для подъёма ([ranking.md](ranking.md#несколько-главных-порядок-типов)).

## Тонкая настройка и справка

Опций много, и они неочевидны. **У каждой опции — справка** из блоков:

- **Что делает** — одна фраза.
- **Если включено** — наблюдаемый эффект: больше или меньше результатов, какие
  появятся секции, группировка, больше или меньше чипов и подсказок «также в…».
- **Если выключено** — то же для выключенного состояния.
- **Когда менять** — типичная ситуация.

Тексты справки пишутся вместе с опцией, а не потом; опция без справки не
принимается на ревью.

Пример:

> **Подъём цитаты к доказываемым сущностям**
>
> *Что делает:* совпадение в тексте цитаты показывается не только у источника, но и
> у персон и событий, которые эта цитата доказывает.
>
> *Если включено:* результатов больше; персоны появляются в выдаче по словам из
> метрических записей о них; у источников становится больше подсказок «также в…».
>
> *Если выключено:* совпадение в цитате приводит только к её источнику; персон в
> выдаче меньше, выдача короче.
>
> *Когда менять:* выключите, если по частому слову («крестьянин») выдача
> заполняется персонами из одного большого источника.

## Хранение настроек

- Настройки выдачи (пресет, опции, порядок типов, группировка) хранятся **на
  пользователя** в базе — у владельца и у приглашённых свои.
- Публичная выдача использует умолчания.
- Текущие опции дублируются в параметрах URL (`preset`, `opt.*`, `group`, `in`),
  чтобы ссылка на выдачу воспроизводила её; параметры URL важнее сохранённых
  настроек.
